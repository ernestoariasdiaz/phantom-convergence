Check a knowledge graph's own numbers before believing them.

Graphs built by LLM pipelines report node counts, edge counts and "confirmed by N sources" scores. graphaudit asks of each number what it would be if nothing interesting were happening, and lists what does not hold up.

What it finds

Every check runs on a CSV export of the graph, with no model and no network. Each one has turned up something real in a graph built by an LLM.

Duplicate nodes

Certain duplicates (case, accents, punctuation, articles), likely ones (typos, plurals, titles, legal forms) and partial names, with guards for numbers, honorifics and opposites.

Sources vs. chance

Is "found in N documents" more than two frequent entities produce anyway? Exact hypergeometric test, Benjamini–Hochberg across all edges.

Counts relationships with no provenance and how connected the graph is without them.

Self-loops

A node linked to itself usually means two entities were merged into one.

Run it

Build with Cargo, export your graph to CSV (converters included for GraphRAG, LightRAG, kg-gen, ai-knowledge-graph and itext2kg) and point graphaudit at it.

# build
$ git clone https://github.com/ernestoariasdiaz/phantom-convergence
$ cd phantom-convergence/graphaudit && cargo build --release

# GraphRAG output (parquet) to CSV, then audit
$ python tools/graphrag_to_csv.py path/to/output graph_csv
$ ./target/release/graphaudit graph_csv/relationships.csv --nodes graph_csv/entities.csv \
      --id title --label title --doc text_unit_ids --undirected

# letterheads and repeated text, without re-indexing
$ python tools/boilerplate.py path/to/output graph_csv/relationships.csv clean

Reliable no model

  • Duplicates, partial names, edge inflation
  • Source support against chance
  • Unsourced edges, self-loops, types, structure
  • Entities copied from the prompt example

Experimental local model

  • --judge: a local LLM decides whether two named entities are the same; useful for review, wrong on generic nodes
  • --embed: embedding similarity; measured, and it rates related things above true duplicates

graphaudit audits; it does not clean. Every list is for a person to review before changing the graph.

Cite

The method comes from auditing ANIMUS, an autonomous knowledge-graph system, where 52% of nodes were duplicates and the flagship "32 sources" edge was at chance level.
